# 对画 · 课时打卡（本地网页试用版）

这是给画室先试用的本地网页，不做微信小程序。数据存在运行服务的那台电脑上的 `data.json` 里。手机和电脑连同一 WiFi，打开同一个地址，看到的是同一份数据。

页面按手机屏幕适配，电脑浏览器也能用。

## 启动

在本目录运行（需已安装 Python 3）：

```bash
python3 server.py
```

Windows 也可以：

```bat
py server.py
```

启动后终端会打印地址，例如：

- 本机：http://127.0.0.1:5173/
- 同一 WiFi 下的手机：http://192.168.x.x:5173/（以终端打印为准）

手机请用这个局域网地址打开，不要只用电脑上的 127.0.0.1。服务需保持运行。若手机打不开，检查是否同一 WiFi，以及电脑防火墙是否放行 5173 端口。

## 本期规则

- 学员打卡选课程和老师，二次确认后扣 1 课时；本期不采集定位
- 剩余 ≤ 0，或当天（北京时间）有效打卡已满 3 次，不能打卡
- 学员自助打卡须距上次有效打卡提交满 3 小时（已取消、已作废不占用；跨天也要间隔）；老师补卡不受这条限制
- 提交成功后 10 分钟内可取消（含老师刚补的卡），课时退回；已取消不计入当日次数
- 老师可改档案、作废打卡、调减课时；补卡只能补当天或过去，不能补未来
- 老师可导出表格（CSV）：先列出学员当前剩余课时，再列出打卡明细

- 同一手机号不允许重复建档；姓名与手机号后四位的组合也须唯一
